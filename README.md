# Apna Ghar Apni Property — Website

A single-page, static website for Apna Ghar Apni Property (Sodepur, Khardaha, Agarpara).

## Files

- `index.html` — page structure and content
- `style.css` — all styling (colours, typography, layout, responsive rules)
- `script.js` — menu, filters, property listings, enquiry form validation and WhatsApp links
- `README.md` — this file

## How to open

Keep all four files in the same folder, then double-click `index.html`. It opens in any modern browser.

Important: keep `index.html`, `style.css` and `script.js` together in the same folder. If they are separated, the page will show without styling or without working features.

## Putting it online

Upload the folder to any static host (for example Netlify Drop, GitHub Pages, or your domain's file manager). Make sure `index.html` is at the root of the site.

## Updating listings

Open `script.js` and edit the `listings` array. Only add properties with verified details. Remove the sample historical listing once the owner confirms its status.

## Adding real photos

Put image files in an `images/` folder next to `index.html`, then replace the illustrative artwork in the matching card or section with `<img src="images/your-photo.jpg" alt="Description">`.
